# 🎯 AI Career Roadmap & Skill Gap Analyzer

## 📌 Overview

AI Career Roadmap & Skill Gap Analyzer is a Machine Learning and NLP-based web application that analyzes a user's resume and provides personalized career guidance.

The application extracts skills from resumes, predicts the most suitable career, identifies missing skills, calculates resume quality, measures career readiness, and recommends a personalized learning roadmap, projects, and certifications.

---

## 🚀 Features

- 📄 Resume Upload (PDF & DOCX)
- 📝 Resume Text Extraction
- 🧠 Automatic Skill Extraction
- 🎯 Career Prediction using Machine Learning
- 📊 Prediction Confidence
- ⭐ Resume Score
- 📈 Career Readiness Score
- 📌 Required Skills Analysis
- ❌ Missing Skill Detection
- 🗓️ Personalized Learning Roadmap
- 💻 Recommended Projects
- 🎓 Recommended Certifications
- 🌐 Interactive Streamlit Web Application

## ▶️ How to Run

Clone the repository

```
git clone https://github.com/yourusername/CareerAnalyzer.git
```

Move into the project folder

```
cd CareerAnalyzer
```

Install required packages

```
pip install -r requirements.txt
```

Run the application

```
streamlit run app.py
```
